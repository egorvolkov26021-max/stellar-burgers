# Тестирование Stellar Burger

- `npm ci` — установить зависимости.
- `npx playwright install chromium` — установить Chromium для e2e.
- `npm test -- --runInBand` — Jest-тесты редьюсеров.
- `npm run e2e` — Playwright-тесты (сервер запускается автоматически).

Тестовые данные API находятся в `tests/hars/`. Токены и пользователь тестовые, не настоящие.
Тесты должны работать без реального API. При изменении верстки может понадобиться адаптировать локаторы.
